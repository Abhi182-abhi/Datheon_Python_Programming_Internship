# Hangman Word Guessing Game

## About Project
This is a Python-based Hangman game.
The user has 6 attempts to guess the hidden word.

## Features
- Random word selection
- Uses random.choice()
- Tracks guessed letters using sets
- ASCII Hangman stages
- Win and Lose conditions
- Prevents duplicate guesses

## Technology Used
- Python 3
- Random Module

## How to Run
python hangman.py


## Task 2: Stock Portfolio Performance Tracker

### About Project
A Python-based stock portfolio tracking application that calculates investment value, current market value, and profit or loss.

### Features
- Accepts stock ticker symbols.
- Takes buying price and share quantity.
- Fetches stock prices using Yahoo Finance.
- Calculates total invested capital.
- Calculates current portfolio value.
- Calculates profit/loss and percentage.
- Saves portfolio records in a CSV file.

### Technologies Used
- Python 3
- yfinance
- CSV Module
- File Handling

### Installation
pip install yfinance

### How to Run
python portfolio.py

### Output
The program generates portfolio_summary.csv containing stock investment and performance details.
